# Nuo Template

### Ultrafast, Component-Driven Admin Ecosystem

**Nuo Template** is a premium, high-end admin template and design system, purpose-built for startups that demand maximum performance, interface consistency, and modularity.

It breaks away from the traditional heavy-dashboard paradigm by leveraging the hybrid power of **Astro, React, and Tailwind CSS**. By rendering static and structural sections on the server (SSR) and activating React surgically — only in highly interactive components — via *Islands Architecture*, Nuo Template guarantees instant load times (Time to Interactive kept to a minimum) and a perfect Lighthouse score.

### Tech Stack

| Technology / Tool | Role in the Project | Purpose & Benefits |
| :--- | :--- | :--- |
| **Astro** | Core Framework | Handles layouts, static routing, and performance optimization. |
| **React** | UI Library | Builds composite components with heavy state logic. |
| **Tailwind CSS** | Styling Engine | Fast styling via utility classes directly in the markup. |
| **Class Variance Authority (CVA)** | Variant Management | Modular design system with strict variant injection for components. |
| **Tailwind Merge** | Class Conflict Resolution | Merges and resolves Tailwind classes without specificity conflicts. |

### Key Features
* **Native Islands Architecture:** Ships 0% client-side JavaScript for static layouts, activating React only where it's actually needed.
* **Enterprise Design System:** Strongly-typed, atomic components built with CVA to prevent visual technical debt.
* **Full Multi-Theme Support:** Includes **6 premium layout themes (such as Catppuccin)**, fully optimized with independent variants for **Dark Mode** and **Light Mode**.
* **Native Dark Mode:** Robust, unified dark mode support powered by native Tailwind CSS classes.
